# DecodeLabs // Advanced Cryptographic Engine Blueprint

A CAD/blueprint-inspired cryptographic dashboard and Python module demonstrating classical substitution and stream ciphers, visual data pipelines, frequency distribution analysis, and automated Chi-Square cryptanalysis.

## Architecture

- **`index.html`**: CAD blueprint UI dashboard.
- **`src/`**: Modular CSS styling, JavaScript graph rendering, and core Python algorithms.
- **`main.py`**: CLI demonstration script.
- **`tests/`**: Unit test suite for verifying cryptographic engine correctness.

## Quickstart

### Running the Web Dashboard
Open `index.html` directly in any web browser.

### Running CLI & Unit Tests
```bash
# Run CLI Demonstration
python main.py

# Run Automated Unit Tests
python -m unittest discover tests
